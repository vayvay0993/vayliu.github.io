rclone mac

A personal OAuth client for rclone

“rclone mac” is a private, single-user OAuth client used only by its owner to let rclone (open-source command-line sync software) access the owner's own Google Drive from a personal Mac.

It is not a public service, does not offer accounts to anyone else, and has no server component. All file transfers happen directly between the owner's computer and Google's APIs.
