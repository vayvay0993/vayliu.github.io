Privacy Policy — rclone mac

Last updated: September 30, 2026

Who uses this app

“rclone mac” is a personal OAuth client used solely by its owner to allow the open-source tool rclone to access the owner's own Google Drive. It is not offered to the public.

What data is accessed

With the user's consent, rclone accesses Google Drive files and metadata in order to list, upload, download and sync files between Google Drive and the user's local computer.

How data is stored and used

OAuth tokens are stored only in the rclone configuration file on the user's own computer. Files are transferred directly between that computer and Google's APIs. No data is sent to, collected by, or stored on any server operated by the app owner.

Sharing

No Google user data is shared with, sold to, or transferred to any third party. Data is not used for advertising, analytics, or training of any models.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from your Google Account permissions page, and by deleting the rclone configuration on the local computer.
